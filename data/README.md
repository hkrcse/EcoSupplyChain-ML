# EcoSC-Sim data (world seed 0)

Simulated records of a 180-day dual-flow supply chain with 4 factories, 8 suppliers, 40 stores, and about 6,380 buyer wallets (6,000 ordinary plus Sybil wallets created by dishonest stores). Generated by `ml/simulate.py`; regenerate any world with `python3 ml/export_dataset.py --seed N`.

These are **synthetic** data. No real person, store, or transaction is represented.

## `sales.csv.gz` — one row per item sold

| Column | Meaning |
|---|---|
| `wallet` | buyer wallet id (0-5999 ordinary, higher ids are Sybil wallets) |
| `store` | selling store id (0-39) |
| `supplier` | supplier that serves the store (0-7) |
| `t_sale` | sale time in days from the start of the run |
| `category` | PET (25 g), CAN (15 g), HDPE (60 g), PACK (10 g) |
| `price_ratio` | price paid relative to list price |
| `prod_age` | product age at sale (days since production) |
| `scheme_tag` | empty for ordinary sales; S1/S3/S4 tag for sales to Sybil wallets |

## `requests.csv.gz` — one row per stage-0 return request

| Column | Meaning |
|---|---|
| `req_id` | request id, ordered by time |
| `wallet`, `store`, `supplier` | claimant buyer wallet, collecting store, its supplier |
| `t_req` | request time (days) |
| `n_items` | number of products in the request |
| `categories` | `;`-separated categories of the products |
| `sale_times` | `;`-separated sale times of the same products |
| `w_exp` | expected weight from the recorded products (g) |
| `w_meas` | weight measured at the collection scale (g) |
| `reward` | reward claimed, in ETH at 0.001 ETH per gram |
| `label` | 1 = fraudulent, 0 = honest |
| `scheme` | `legit`, `S1_phantom`, `S2_inflate`, `S3_ring`, `S4_lowslow` |

## `features.csv.gz` — model input

All columns of `requests.csv.gz` except the lists, plus the 39 features listed in `ml/features.py` (`GROUPS`), and `audited` (whether the request was drawn for the random 5% audit). Every feature uses only events before the request time.

## Legitimate behavior that resembles fraud

Bulk buyers (1% of wallets), two-week promotions at six stores, batch uploads at four stores, containers with residue (4% of returns, +8-20% weight), and scales reading 12% low at three stores for a month.
